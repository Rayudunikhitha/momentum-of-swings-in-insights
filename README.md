# Momentum of Swings in Insights

## 📌 Project Overview

Momentum of Swings in Insights is a swing trading project that explores
technical and fundamental analysis to identify medium-term market
opportunities.

## 🎯 Objectives

- Understand swing trading strategies
- Analyze technical indicators
- Study fundamental indicators
- Apply risk management techniques
- Explore Python and Machine Learning for trading analysis
- Validate strategies through backtesting

## 🛠️ Technologies

- Python
- Machine Learning
- Technical Analysis
- Fundamental Analysis
- Data Analysis
- Backtesting

## 📊 Key Concepts

- EMA
- SMA
- Stochastic Momentum Index (SMI)
- Heikin-Ashi Candlesticks
- Market Capitalization
- P/E Ratio
- ROE & ROCE
- Risk-Reward Ratio
